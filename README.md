# Claude Co-Work Workshop 🛠️

Welcome to the **Claude Co-Work Workshop** repository! This repository contains a collection of curated guides and interactive resources designed to help you master prompt engineering, workflow design, and building robust systems around artificial intelligence.

---

## 📚 Contents

This repository features the following resources:

### 1. [The AI Operator Method](AI%20Operator%20Method_%20Claude%20Project%20Workflow%20Guide%20_%20Claude.html)
* **File**: `AI Operator Method_ Claude Project Workflow Guide _ Claude.html`
* **Description**: A highly visual, four-step playbook for converting a folder of unstructured project context into a repeatable, high-quality workflow using Claude Projects.
* **The Core Loop**:
  1. **Gather**: Curate the necessary files, brand guides, templates, and raw data.
  2. **Brainstorm**: Collaborate with Claude as an active strategy partner to surface blind spots.
  3. **Draft**: Refine the project output structure in plain text before final generation.
  4. **Build**: Synthesize the draft into the final target artifact.
* **Key Feature**: Includes a ready-to-copy project kickoff prompt designed for building repeatable slide deck generators or other document automation tasks.

### 2. [The Field Guide to AI's Limitations](The%20Field%20Guide%20to%20AI%27s%20Limitations.html)
* **File**: `The Field Guide to AI's Limitations.html`
* **Description**: A comprehensive interactive resource outlining the common pitfalls, cognitive limitations, and failure modes of Large Language Models (LLMs)—and, more importantly, how to architect solutions around them.
* **Themes Covered**:
  * Identifying when and why models hallucinate or lose context.
  * Practical UI/UX patterns and prompt safeguards to keep AI systems reliable.
  * System-level solutions for robust software development with AI integrations.
