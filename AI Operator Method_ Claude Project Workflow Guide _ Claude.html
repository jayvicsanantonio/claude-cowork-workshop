Claude Project Playbook

The AI Operator Method

A four-step rhythm for turning a folder of context into a repeatable Claude workflow that does real work, the same way, every time.

The Loop
01

Gather

Pull together the templates, data, voice, and examples Claude needs to do the job.

02

Brainstorm

Think out loud with Claude as a strategy partner before committing to a direction.

03

Draft

Lock the narrative in plain text and approve it before a single slide gets built.

04

Build

Hand the approved plan to the template and ship the finished artifact.

Where this prompt fits in

Once you finish the Gather step and have your ingredients dropped into a Claude Project, you need to show Claude the work and get it pointed in the right direction.

The prompt below does that. Paste it as the first message in a brand-new project. Claude looks around at the context you collected, then interviews you with smart questions before it writes anything. The result is project instructions tuned to your work, not a guess.

This example is built for a monthly investor update deck. Swap the inputs and it works for any recurring deliverable you run through a template.

first-message.txt
You're helping me build the project instructions for this Claude Project. The goal is a repeatable workflow that produces my monthly investor update deck accurately and on brand, every single time. Start by looking around this project. I've gathered the inputs you'll need: - Last month's deck (the template to match) - A cheat sheet on what my investors care about - My brand voice guide - This month's raw source data (CRM, revenue, runway) Before you write a single line of instructions, interview me with a series of smart multiple choice questions so we land on the same page about what these instructions need to cover. When you write the instructions, set up a four phase workflow: GATHER Always confirm I've collected every input the deck needs. The asks from my last investor call, deal data, revenue and runway numbers, and any other updates. Handle paste-ins. Validate I have everything before moving forward. BRAINSTORM Be a strategy partner, not a yes-man. Use the cheat sheet and how I've done this before. Surface blind spots, push back, and help me focus on the right amount for a five slide update. Act a little like one of my investors. DRAFT Output only the narrative for each slide as plain text in chat. The core story and key data points per slide. Wait for my approval before you build anything. BUILD Once I approve the narrative, build the deck from the template and follow the brand voice. Also analyze the template and propose a loose schema this project should synthesize content into. The finished deck is always exactly five slides. Ask your multiple choice questions now.

Pro tip. Keep the Build step inside the instructions for now. Once the workflow proves itself, ask Claude in a separate chat to spin the build phase out into a reusable skill that generates the final file on command.

What to put in the folder

The Operator Method is only as good as the Gather step. These are the context files worth collecting and curating before you start a Claude Project. Aim for a few strong files in each category, not a dump of everything.

The Shape

Templates

The exact file and format you want filled in, so output matches structure on the first try.

e.g. last month's .pptx, a doc skeleton
The Shape

Reference examples

One or two finished pieces that landed well. Claude pattern-matches quality from these.

e.g. the update investors praised
The Voice

Brand and style guide

How things should sound and look so the output reads like you, not generic AI.

e.g. tone rules, words to avoid
The Voice

Decision cheat sheet

What your audience cares about and how you prioritize. Fuels the brainstorm phase.

e.g. what your investors push on
The Substance

Source data

The raw inputs that change each cycle. Exports, numbers, and metrics to pull from.

e.g. CRM export, revenue, runway
The Substance

Stakeholder asks

Specific requests from named people so nothing requested last time gets dropped.

e.g. the follow-ups from your last call
The Guardrails

Hard constraints

Non-negotiable rules on length, count, or format that the output must always honor.

e.g. exactly five slides, no jargon
The Guardrails

Process notes

How you've done this before and what you learned. Saves repeating the same direction.

e.g. lessons from past months
